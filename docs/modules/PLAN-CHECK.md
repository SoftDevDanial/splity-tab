### New FLAG (should fix)
- [5] split-app allowed difference 7 and the DOM contract sentence "A block that is not rendered is either absent or carries the `hidden` attribute". Allowed difference 7 says any element with `hidden` is not rendered, so the R3 walk skips it. That is false for every class to which `system.css` gives a `display` value, because an author `display` beats the `[hidden]` rule of the browser, and `system.css` has no `[hidden]` rule and cannot change. Measured on `bill-even.html` at 390, `hidden` leaves `button.copy` as `inline-flex`, `ul.cells` as `grid` and `span.field` as `flex`, each still on screen, and `div.note` (`flex`) would stay too. It does remove `section.block`, `p.status` and `table.shares`. A builder who hides Copy summary or the note with `hidden` ships a visible element that the R3 walk skips. Fidelity on S3 and S5, R17 and R18 ("no Copy summary") and R27 ("no longer in the DOM") would still catch it, so nothing wrong ships, but it costs a rework loop. → Let the R3 walk skip an element only when its computed `display` is `none` (a closed dialog, or `hidden` on an element whose class has no `display` rule). Say in the DOM contract that a conditional element is either absent or carries `hidden` only where `system.css` gives it no `display` (for example `section.block`, `div.note-wrap`, `table.shares`, `p.status`).
