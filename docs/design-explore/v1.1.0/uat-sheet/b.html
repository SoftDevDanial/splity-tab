About this proposal (not part of the layout) · B of 3 · Test sheet

Each case is one sheet of paper with a big case number, every part in a table, and the four verdicts drawn like a ballot so the chosen one stands out. The figures you must check have their own tick boxes. It bets on the easiest read and the best look in the public showcase, and it prints one case per page. It costs a second file, because the Markdown file stays the record and this page is generated from it.
