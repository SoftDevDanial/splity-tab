How to give a verdict

Every case gets a verdict, including the ones you could not do. The tester column is already filled. If it says PASS and you find FAIL, that is one of the most useful things you can tell us.

VerdictWhat it meansExample
PASSIt does what the case says, at every step.UAT-02. The shares read RM 38.87, RM 38.87 and RM 38.86, exactly as listed.
PASS + noteIt works, and you want something changed. The note becomes a finding for a later version. It does not fail the case.UAT-03. "Pass but i prefer if it cannot be evenly split, the number in summary should show the extras". This became scope S1 of 1.1.0.
FAILSomething on screen differs from the You should see column. Name the step and what you saw.Step 10. Ben's charges read RM 2.25, the sheet says RM 2.24.
BLOCKEDYou could not run it. Say why. The control was not where the sheet said, the start could not be reached, or the result was not something you could see.Step 2 says click Add item, but there is no button with that name.
